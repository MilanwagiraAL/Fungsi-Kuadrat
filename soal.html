Latihan Soal

Silakan pilih jawaban yang menurut Anda benar. Klik tombol di bawah untuk melihat skor dan pembahasan detail.

1. Pembuat nol dari fungsi kuadrat $f(x) = x^2 + 6x + 5$ adalah $\dots$
2. Jika grafik fungsi kuadrat $f(x) = ax^2 + bx + c$ dengan titik puncak $(5, -4)$ memotong sumbu X positif dan sumbu X negatif, maka pernyataan yang benar adalah $\dots$
3. Jika grafik fungsi $y = x^2 + ax + b$ mempunyai titik puncak $(1, 2)$, maka nilai $a$ dan $b$ adalah $\dots$
4. Garis $g$ menyinggung parabola $y = x^2 - 3x + 1$ di titik $P$. Jika absis titik $P$ adalah $x_p = 3$, maka persamaan garis $g$ adalah $\dots$
5. Koordinat titik puncak grafik fungsi kuadrat $y = 2x^{2} + 2kx + k + 5$ adalah $(m, m)$. Nilai $k + m = \dots$
6. Fungsi kuadrat $y = f(x)$ yang grafiknya melalui titik $(2, 5)$ dan $(7, 40)$, serta mempunyai sumbu simetri $x = 1$, mempunyai nilai ekstrem $\dots$
7. Jika $2a + 1 < 0$ dan grafik $y = x^2 - 4ax + a$ bersinggungan dengan grafik $y = 2x^2 + 2x$, maka nilai dari $a^2 + 1 = \dots$
8. Sumbu simetri grafik $f(x) = ax^2 + bx + c$ adalah $x = 1$. Jika $f(0) = 0$ dan $f(4) = -16$, maka nilai $b - a$ adalah $\dots$
9. Grafik fungsi $f(x) = mx^{2} + (2m-1)x + m + 3$ berada seluruhnya di atas sumbu X. Interval nilai $m$ yang memenuhi adalah $\dots$
10. Jika fungsi kuadrat $f(x) = ax^2 + (a+6)x + 3$ puncaknya berordinat $5$, maka nilai $a = \dots$
11. Diketahui $f(x) = (x - a)(x - b)$ dengan $a, b,$ dan $x$ bilangan real dan $a < b$. Pernyataan berikut ini yang benar adalah $\dots$
12. Jika grafik fungsi kuadrat $f(x) = (2 - a)x^2 + (a + \sqrt{2})x + a + \sqrt{2}$ selalu berada di atas sumbu X untuk interval $m < a < n$, nilai dari $m - 5n = \dots$
13. Titik $(a, b)$ terletak pada grafik $y = bx^2 + (1 - b^2)x - 56$. Jika $a - b = 7$, maka nilai $ab$ adalah $\dots$
14. Jika puncak parabola $y = x^2 - (a + 1)x + (2a + 4)$ terletak pada garis $y = 3x$, maka nilai $a = \dots$
15. Koordinat titik potong grafik fungsi kuadrat $y = 3x^2 - x - 2$ dengan sumbu X dan sumbu Y adalah $\dots$
16. Jika grafik fungsi $y = x^2 - (9 + a)x + 9a$ diperoleh dari grafik fungsi $y = x^2 - 2x - 3$ melalui pencerminan terhadap garis $x = 4$, maka nilai $a = \dots$
17. Fungsi kuadrat yang memiliki nilai minimum $2$ untuk $x = 1$ dan mempunyai nilai $3$ untuk $x = 2$ adalah $\dots$
18. Fungsi kuadrat $f(x) = x^2 + 2px + p$ mempunyai nilai minimum $-p$ dengan $p \neq 0$. Jika sumbu simetri kurva $f$ adalah $x = a$, maka nilai $a + f(a) = \dots$
19. Grafik fungsi $y = ax^2 + bx - 1$ memotong sumbu X di titik-titik $\left(\frac{1}{2}, 0\right)$ dan $(1, 0)$. Fungsi ini mempunyai nilai ekstrem $\dots$
20. Jika grafik $f(x) = ax^{2} + (2a+6)x + 2a - 2$ menyinggung sumbu X, maka koordinat titik balik maksimumnya adalah $\dots$
21. Grafik fungsi kuadrat $y = (x - 2a)^2 + 3b$ mempunyai nilai minimum $21$ dan memotong sumbu Y di titik yang berordinat $25$. Nilai $a + b$ adalah $\dots$
22. Jika fungsi kuadrat $f$ memiliki sifat-sifat: $f(x) \geq 0$ untuk semua bilangan real $x$, $f(1) = 0$, dan $f(2) = 2$, maka nilai $f(0) + f(4)$ adalah $\dots$
23. Diketahui nilai minimum fungsi kuadrat $y = x^2 + bx + c$ adalah $\left(\frac{5}{2}, -\frac{1}{4}\right)$. Jika grafik fungsi tersebut melalui titik $(p, 0)$ dan $(q, 0)$, maka nilai dari $p^2q + pq^2$ adalah $\dots$
24. Suatu fungsi kuadrat $f(x)$ mempunyai nilai maksimum $5$ untuk $x = 2$, sedangkan $f(4) = 3$. Fungsi kuadrat tersebut adalah $\dots$
25. Jika grafik fungsi $y = x^2 + 2mx + m$ berada seluruhnya di atas grafik $y = mx^2 + 2x$, maka batasan nilai $m$ adalah $\dots$
26. Jika grafik fungsi kuadrat $f(x) = ax^2 + bx - c$ mempunyai titik puncak $(1, -4)$ dan memotong sumbu X negatif, maka pernyataan yang benar adalah $\dots$
27. Jika fungsi kuadrat $y = ax^2 + 6x + (a + 1)$ mempunyai sumbu simetri $x = 3$, maka nilai maksimum fungsi itu adalah $\dots$
28. Fungsi kuadrat yang grafiknya melalui titik $(-1, 2)$ dan titik tertingginya sama dengan titik terendah dari grafik $f(x) = x^2 + 4x + 7$ adalah $\dots$
29. Untuk $0 < a < 10$, fungsi kuadrat $f(x) = ax^2 + 2ax + 10$ memenuhi sifat $\dots$
30. Fungsi kuadrat $y = ax^2 + x + a$ definit negatif untuk konstanta $a$ yang memenuhi $\dots$
31. Titik $P(x_{0},y_{0})$ dan titik $Q$ adalah dua titik yang terletak simetris pada parabola $y = a\left(x + \frac{b}{2a}\right)^2 - \frac{D}{4a}$. Absis titik $Q$ adalah $\dots$
32. Jika parabola $y = ax^2 - (a + 3)x + a$ menyinggung sumbu X dan terbuka ke bawah, maka nilai $a = \dots$
33. Diketahui $b$ merupakan suatu bilangan bulat dan $p$ merupakan suatu bilangan prima. Jika grafik $y = x^2 + bx + p$ memotong sumbu X negatif di dua titik berbeda, maka nilai $b - p$ adalah $\dots$
34. Jika grafik fungsi $f$ memotong sumbu X di titik $A(a,0)$ dan $B(a+6,0)$, maka koordinat titik puncak grafik fungsi $f$ yang mungkin adalah $\dots$
35. Koordinat titik balik grafik fungsi kuadrat $f(x) = 2x^{2} - 4x + 5$ adalah $\dots$
36. Grafik fungsi $f(x) = x^2 - 6x + 7$ dapat diperoleh dengan cara menggeser grafik fungsi $f(x) = x^2$ ke arah $\dots$
37. Jika kurva $y = (m - 2)x^2 - mx + 5$ membuka ke atas dan dipotong oleh garis $y = mx - 4$, maka batasan nilai $m$ adalah $\dots$
38. Interval nilai $p$ yang menyebabkan fungsi kuadrat $f(x) = px^2 - (2p + 3)x + p + 2$ definit negatif adalah $\dots$
39. Fungsi kuadrat $f(x) = ax^2 - (2a - 4)x + (a + 4)$ selalu bernilai positif untuk nilai $a$ yang memenuhi $\dots$
40. Jika $f$ adalah fungsi kuadrat yang grafiknya melalui titik $(-1, 0), (2, 0),$ dan $(0, 2)$, maka nilai $f(7)$ adalah $\dots$
41. Jika $(p, q)$ merupakan titik puncak grafik fungsi $f(x) = ax^2 + 2ax + a + 1$, dengan $f(a) = 19$, maka nilai dari $p + 2q + 3a = \dots$
42. Jika grafik fungsi kuadrat $f(x) = ax^2 + bx + c$ mempunyai titik puncak $(8, 4)$ dan memotong sumbu X negatif, maka pernyataan yang benar adalah $\dots$
43. Fungsi kuadrat yang grafiknya melalui titik $(-1, 3)$ dan titik terendahnya sama dengan puncak dari grafik $f(x) = x^2 + 4x + 3$ adalah $\dots$
44. Absis titik balik grafik fungsi $y = px^2 + (p-3)x + 2$ adalah $p$. Nilai $p = \dots$
45. Diketahui fungsi kuadrat $f(x) = 2x^{2} - 7x - 5$ serta titik $A(2,-11), B(-1,0),$ dan $C(-4,55)$. Titik yang dilalui grafik fungsi $f(x)$ adalah $\dots$
46. Agar grafik fungsi $f(x) = (p+6)x^{2} + px + 2$ memotong sumbu X di dua titik berbeda di sebelah kanan titik asal $O(0,0)$, maka nilai $p$ haruslah $\dots$
47. Jika titik $P(-3,5)$ dan $Q(7,5)$ terletak pada grafik fungsi $f(x) = p(x-q)^{2} + r$, maka nilai $q = \dots$
48. Grafik parabola yang melalui titik $(0,0)$ mempunyai sumbu simetri $x = 4$ dan puncak parabola terletak pada garis $x - y + 4 = 0$. Persamaan parabola tersebut adalah $\dots$
49. Jika parabola $y = (n-1)x^{2} - (n+1)x + 3 - 2n$ untuk $n \neq 0, n \neq 1,$ dan $n$ bilangan real selalu melalui dua titik tertentu, yaitu $(a, b)$ dan $(p,q)$, maka nilai dari $a + b + p + q = \dots$
